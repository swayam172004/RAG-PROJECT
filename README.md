# RAG PDF Chatbot

A Retrieval-Augmented Generation (RAG) application built with:

- Streamlit
- Groq
- FAISS
- Sentence Transformers
- PyPDF

## Features

- Upload PDF
- Create Embeddings
- Store Embeddings in FAISS
- Semantic Search
- LLM Powered Answers

git clone https://github.com/yourusername/rag-chatbot.git
